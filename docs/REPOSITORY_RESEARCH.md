# Repository research

**Reviewed:** 2026-10-11. Candidate repositories were shallow-cloned to a temporary directory for read-only inspection; no code was copied or installed. Clone revisions below are snapshots and should be refreshed before implementation. README claims were cross-checked with selected source files and license files; no isolated runtime/security evaluation was performed.

## Feature inventory and reuse decision

| Feature | Evidence/source | Decision | Effort / required validation |
|---|---|---|---|
| Hook verdict normalization | Cerberus `src/hook/adapters.ts`; Reflex `hook.mjs`; Claude Warden `src/` | INSPIRE interface; implement GuardSaaB-owned adapter | Medium; agent version contract, malformed input, timeout, failure modes |
| Shell structure/effects | Claude Warden bash-parser claim; Reflex `shell.mjs` lexical parsing | REIMPLEMENT/ADAPT only after parser selection; no parser alone establishes effects | High; adversarial syntax corpus, nesting, shell variants, conservative uncertainty |
| Deterministic policy | Cerberus `src/policy/`; Reflex `policy.mjs`/`gate.mjs`; Claude Warden rules | INSPIRE data-driven policy; own stable schema | Medium; precedence, default behavior, policy mutation/version tests |
| Approval lifecycle | Cerberus `src/engine/server.ts`; Reflex human queue patterns | REIMPLEMENT with server-authenticated action-bound approvals | High; replay, expiry, race, changed action/context, unauthorized approver |
| Session timeline/replay | Cerberus `src/audit/projector.ts`; Reflex `replay.mjs` | INSPIRE projection from event log | Medium; gaps, duplication, deterministic reconstruction |
| File/MCP/other tools | Candidate docs expose varying hooks; no common comprehensive boundary | REIMPLEMENT per adapter; defer beyond first action subset | High; individual tool and bypass testing |
| Agent registry/team administration | Candidate fleet views are not a governed identity registry | REIMPLEMENT later | High; auth, tenancy, owner/project/environment bindings |
| Emergency controls | Warden orchestrator kill switch docs; Cerberus pending holds | INSPIRE ability to block future actions; no rollback claim | Medium/high; process lifecycle and race behavior |

No third-party runtime component is approved for reuse yet. The first milestone should implement a minimal owned adapter and policy path, then consider isolated reuse based on test and security review. No repository has been independently penetration-tested here.
