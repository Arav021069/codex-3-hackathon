# Deployment

There is no deployable application yet. The first milestone targets a local developer installation with an agent hook and local decision service.

Before shipping, document prerequisites, supported OS and agent versions, install/uninstall behavior, loopback binding, ports, config schema, protected defaults, local data location, file permissions, log redaction, policy backup/migration, upgrades, rollback, crash recovery, and offline behavior. Do not pipe remote installers directly into a shell without pinned/reviewable artifacts and integrity verification. Do not add production cloud deployment or credentials until a supported deployment model is selected.
